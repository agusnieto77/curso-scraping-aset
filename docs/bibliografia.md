# Bibliografía y recursos

- Wickham, H. (2024). *rvest: Easily Harvest (Scrape) Web Sites*. R package.
  https://rvest.tidyverse.org
- Wickham, H. & Hesselberth, J. (2024). *httr2: Perform HTTP Requests and Process the Responses*.
  R package. https://httr2.r-lib.org
- Wickham, H., Çetinkaya-Rundel, M. & Grolemund, G. *R for Data Science* (2ª ed.). O'Reilly.
  https://r4ds.hadley.nz — **Cap. 24: Web scraping**
